Privacy Policy

Claude Gmail MCP is a personal-use tool run solely by its owner, on the owner's own computer, against the owner's own Gmail account.

  • Gmail data accessed through Google APIs is used only to carry out the owner's own requests (reading, searching, labelling and managing their own mail).
  • OAuth tokens are stored locally on the owner's computer and are never sent to any server other than Google.
  • No data is sold, shared with third parties, or used for advertising.
  • Access can be revoked at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
